## Отдельное содержательное изменение после первого запуска

Проверка крайних случаев выявила неоднозначность встроенного IDNA-кодека Python: Unicode-имя `faß.de` может преобразовываться в `fass.de`. Для журнала агента такое неявное сопоставление нежелательно.

Исправление отклоняет не-ASCII имена с необратимым IDNA-преобразованием. Для них нужно указать точное ASCII/Punycode-имя. Это намеренно ограниченная, консервативная политика; она не реализует все браузерные стандарты URL и не проверяет DNS, redirects или сетевое выполнение.

Добавлены семь автоматических сценариев: неоднозначные Unicode-преобразования, проверка исключения из allowlist, точное Punycode-сопоставление, URL с userinfo и чтение CLI встроенного примера. Локальная сборка и тестирование установленного wheel после изменения: **79 тестов прошли**. Повторная публикация изменения должна вызывать отдельный CI run; его фактический статус проверяется в Actions.

## Как воспроизвести локально

```bash
python -m pip install -r requirements-dev.txt
python -m build --no-isolation
python -m pip install --force-reinstall --no-deps dist/agentgate-1.0.0-py3-none-any.whl
python -m pip check
python -m pytest -v --junitxml=reports/pytest.xml
```

Положительная учебная трасса должна дать exit code 0, трасса с нарушениями — 1. Для проверки реального изменения можно изменить тест или политику, зафиксировать отдельный commit и опубликовать его в собственной ветке. Намеренно сломанный тест в основной ветке для демонстрации не требуется.
